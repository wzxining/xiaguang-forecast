# 霞光观测站

展示网址：https://wzxining.github.io/xiaguang-forecast/

面向个人非商业课堂展示的朝霞、晚霞观赏参考网站。无需购买域名或运行服务器。

## 功能

- 点击搜索框先显示推荐城市，输入城市名列出该城市全部已收录景点；也支持直接搜景点名。选中景点后按它自己的 WGS84 参考坐标查询未来三天日出、日落时间和实验性观赏指数。网页打开时每五分钟重新请求预报；从后台返回且超过五分钟时也会更新。天气提供方不一定每五分钟发布新数据，因此结果可能相同。
- 每个景点用独立卡片展示未来三天预报，三天从上到下排列，蓝色条表示朝霞、橙色条表示晚霞，并显示分数、日出日落时间及原因。城市整体参考放在景点列表下方，使用单独的市区参考坐标查询。当前有 23 座城市、44 个附来源的景点，均有坐标参考位置；这是全部已收录景点，不是全国完整名录。可手动查找 OpenStreetMap 附近候选点（最多 60 条返回记录），新候选点也使用自己的地图坐标，地图服务失败时给出明确提示和地图入口。
- 顶部“我的观霞”保存城市和景点收藏，可导入、导出 JSON。收藏保存在当前浏览器，按已验证的 GitHub 账号区分；访客收藏单独保存，不会自动跨设备同步。
- 使用 Giscus 的 GitHub 登录发表评论。留言写入本仓库的 Discussions，仓库所有者可直接查看和回复。每个账号使用一个公开留言帖，在个人页面查看本网站留言记录及站长回复。没有 GitHub 账号的访客可通过页面链接注册。

## 留言配置

本仓库已启用 Discussions 并安装 Giscus。`community.js` 中的仓库 ID、分类 ID 都是公开配置，不是密钥。初始留言大厅为 Discussion #1；成功登录后按已验证的 GitHub 用户名切换到个人留言帖。个人帖在首次留言时自动建立。

本站不读取 GitHub 密码，不要求访客输入访问令牌。认证由 GitHub/Giscus 完成。留言公开可见，请勿填写私人信息。网络无法访问 Giscus 时，可直接打开仓库 Discussions。

根目录部署文件：`index.html`、`style.css`、`app.js`、`weather.js`、`community.js`、`spots.js`、`spot-coordinates.js`、`cities.js`、`CITY-DATA-LICENSE.txt`。

## 数据与边界

- 气象：[Open-Meteo](https://open-meteo.com/)，适用其[非商业使用条款](https://open-meteo.com/en/terms)。指数综合日出、日落前后约 90 分钟的分层云量、降水概率和能见度，**未经过实测校准，不是霞光出现概率**。景点查询坐标保留到小数点后六位，按坐标缓存五分钟，同时同地点请求合并、最多三个请求并行。实际天气来自数值预报网格，邻近景点可能共用网格；返回的网格参考坐标也会展示。不能把坐标精度当成天气精度。
- 城市：[City Geo](https://github.com/88250/city-geo)，木兰宽松许可证第 2 版，完整许可证见 `CITY-DATA-LICENSE.txt`。城市中心坐标经过近似转换及部分修正，用于城市索引、附近候选点范围搜索和下方城市概况，不代替景点天气查询；在线补充搜索使用 Open-Meteo / GeoNames。城市索引不等于全部行政区划或县级市名录。
- 景点：`spots.js` 包含逐条资料来源和自行撰写的短摘要。它不代表全国每座城市的完整景点名录；开放、预约、潮汐及交通信息须以景区当日公告为准。
- 景点参考坐标：`spot-coordinates.js` 保存 WGS84 坐标、参考位置说明及逐条来源。部分是景区中心、山顶、湖区或邻近园区参考位置，并非精确摄影机位，页面明确标注。有来源的同名地点经过城市位置复核，拒绝误匹配到外地的结果。大范围滨海步道使用明示的代表路段，不能代表整条步道。旧收藏按景点 ID 对应最新核实坐标。
- 坐标来源以 OpenStreetMap 为主；小鱼山北门、浐灞国家湿地公园和北高峰山顶使用 Wikimedia Commons 原始摄影记录中的公开坐标（结构化数据 CC0），来源分别链接到原文件说明页；不转载摄影图片。Nominatim 只用于开发时有限的一次性位置核对，单线程、间隔至少 1.2 秒、缓存结果，网站运行时不调用 Nominatim，也不用于自动补全。遵守其[使用政策](https://operations.osmfoundation.org/policies/nominatim/)。
- 2026-10-10 补充杭州城市阳台、宝石山蛤蟆峰、马家坞纳福云台、北高峰山顶，上海宝山滨江公园、南京鱼嘴湿地公园。观赏资料采用可打开的公开游记、杭州网及地方公开报道，未将无法核验正文的小红书笔记作为证据。杭州前三处坐标来自公开游记提供的近似 WGS84 参考点，卡片明确标注近似坐标，并附资料链接；不声称精确摄影机位。
- 地图候选：[OpenStreetMap contributors](https://www.openstreetmap.org/copyright)，ODbL。按城市中心附近范围查询，可能跨行政边界；不保证日落视野。地图候选查询结果在当前浏览器缓存 24 小时。
- 临时连接失败、超时和服务端繁忙会自动重试一次；遇到限流遵循等待时间（至少一分钟），不会立即重复请求。切换城市时会取消旧城市正在执行或排队的天气查询。
- 成功的天气结果按景点坐标保存在当前浏览器，刷新网页后仍能复用五分钟内的缓存。最新查询失败时可回退到当天、六小时以内的同景点缓存，明确显示获取时间；跨天或超过六小时即弃用。最多保存 100 个地点，浏览器禁用存储时仍能查询实时预报。
- API 失败不会生成虚构预报或景点。缺少坐标、未收录地点、超时、连接失败、服务限流、数据不完整分别显示原因。

## 回归检查

运行 `node tests/weather.test.cjs` 检查自动重试、持久缓存、缓存过期与跨天、限流、超时、取消旧城市请求以及存储不可用场景。

## 本地预览

在此目录运行 `python3 -m http.server 8876 --bind 127.0.0.1`，打开 http://127.0.0.1:8876/ 。GitHub 登录需要网页地址，请勿直接双击 HTML 文件使用 `file://` 进行登录测试。需要联网才能加载气象预报与留言。
